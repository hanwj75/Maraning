# Cute Design Rules

## Visual Principles

- 전체 UI 는 짧은 영어 학습 루프에 맞는 가볍고 반응 빠른 인상을 줘야 한다.
- 귀여운 UX 는 장식보다 정서적 완충 장치 역할을 해야 한다.
- 화면은 한 번에 한 가지 핵심 행동만 강조해야 한다.
- 시선 흐름은 `현재 상태`, `다음 행동`, `보상 또는 피드백` 순으로 읽혀야 한다.

## Tone Direction

- 분위기는 밝고 말랑한 학습 보조 앱에 가깝게 유지한다.
- 캐릭터와 아이콘은 친근해야 하지만 과하게 유아적이면 안 된다.
- 짧은 세션에 맞게 전체 화면 밀도는 낮고 이해 속도는 빨라야 한다.

## Layout Rules

- 각 화면의 핵심 CTA 는 화면 하단 또는 중앙에서 명확히 보여야 한다.
- 주요 정보는 큰 카드 또는 큰 블록으로 나눠 한눈에 읽히게 한다.
- 콘텐츠 그룹 간 간격은 넉넉하게 두어 답답함을 줄인다.
- 작은 버튼은 금지한다.
- 탭 가능한 요소는 손가락 기준으로 충분히 큰 영역을 가져야 한다.
- Quiz 화면에서는 보기 영역을 우선 넓게 확보하고, 캐릭터와 하트는 제출 버튼 아래로 내려야 한다.

## Color Direction

- 색상은 부드럽고 따뜻한 파스텔 계열을 기본으로 한다.
- 상태 표현은 명확해야 하며, 귀여움 때문에 의미 구분이 흐려지면 안 된다.
- 성공은 밝고 산뜻한 색, 실패는 과하게 위협적이지 않은 경고색, 잠금 상태는 부드러운 중성색을 사용한다.
- `jelly` 관련 상태는 직관적으로 식별 가능한 포인트 색을 유지한다.

## Typography Direction

- 짧고 큰 문구를 우선한다.
- 설명 텍스트는 최소화하고, 한 문장 길이를 짧게 유지한다.
- 제목은 빠르게 읽히는 둥근 인상의 서체 톤을 목표로 한다.
- 긴 설명은 금지한다.

## Component Tone

- 버튼, 카드, 배지, 스테이지 노드는 둥근 모서리와 부드러운 볼륨감을 가진다.
- 정답 선택 요소는 눌렀을 때 즉시 반응해야 한다.
- 빈 상태나 잠금 상태도 차갑지 않게 표현한다.
- `jelly` 부족 안내는 압박보다 회복 가능성을 보여주는 톤이어야 한다.
- `FAIL LIFE` 같은 시스템 텍스트는 노출하지 않고, 하트만 캐릭터 머리 위에 떠 있는 느낌으로 보여준다.
- `jelly` 배지는 한 화면에 하나만 두고 `젤리 {current}` 한 줄만 사용한다.
- Quiz 하단에는 설명 카드나 추가 텍스트를 붙이지 않고 캐릭터 이미지와 하트만 남긴다.

## Forbidden Patterns

- 시험지 UI 는 금지한다.
- 텍스트가 많은 설명 패널은 금지한다.
- 같은 정보를 반복하는 중복 상태 UI 는 금지한다.
- 작은 버튼, 촘촘한 선택지, 긴 지시문은 금지한다.
- 회색 위주의 건조한 학습 도구 톤은 피한다.
